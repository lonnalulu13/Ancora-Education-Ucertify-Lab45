# Creating a User Account in the Active Directory




## Objective of the Lab 
In this lab, you will learn to create a user account in the active directory. A domain user is a user whose username and password are stored on a domain controller rather than the computer that the user is logging into. 
## Instructions 
### STEP 1 
From the bottom-left bar, click the WIN16 tab, and then click On/Connect to power on the machine. 
### STEP 2 
On the taskbar, click the Search Windows icon and in the Search textbox, type Windows Administrative Tools and then click on it to open the Administrative Tools window. 
### STEP 3 
In the Administrative Tools window, double-click Active Directory Users And Computers. 
### STEP 4 
In the Active Directory Users And Computers window, from the left pane, navigate to ucertify.livelabs > Users. 
### STEP 5 
Right-click Users and navigate to New > User. 
### STEP 6 
In the New Object - User window, perform the following steps: 

a.Type the following details and click Next: 
 
  1.First name: Peter 
 
  2.Last name: Evans 
  
  3.User logon name: pevans 

b.Type the Password as ucertify@123, Confirm password as ucertify@123, and click Next. 

c.Click Finish to create the new user. 
### STEP 7 
Close all windows.
